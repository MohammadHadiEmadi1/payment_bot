## این بات چیکار می‌کنه

فرض کن چند نفر تو یه اتاق/خونه‌ی مشترک زندگی می‌کنن. هر از گاهی یکی‌شون یه هزینه‌ی مشترک می‌ده (خرید، قبض، پیتزا و غیره) و بقیه باید سهم خودشون رو بهش برگردونن. این بات دقیقاً همین حساب‌وکتاب رو خودکار می‌کنه:

- هرکس با یه اسم مستعار عضو می‌شه
- هر هزینه‌ای که ثبت می‌شه، بات خودش حساب می‌کنه کی چقدر بدهکار/طلبکار شده
- در هر لحظه می‌شه با یه دستور دید کی به کی چقدر بدهکاره
- وقتی کسی بدهیش رو صاف کرد (پول واریز کرد)، با یه دستور ثبت می‌شه
- تاریخچه‌ی کامل تراکنش‌ها هم قابل مشاهده‌ست

همه‌چیز داخل خودِ گروه تلگرام اتفاق می‌افته، نیازی به اپ یا سایت جدا نیست.

## چرا همیشه روشنه؟ (Cloudflare Workers)

این بات روی یه سرویس به اسم **Cloudflare Workers** اجرا می‌شه، نه روی یه سرور معمولی. این فرق مهمیه:

**سرور معمولی:**
یه کامپیوتر/سرور باید ۲۴ ساعته روشن بمونه و منتظر پیام بمونه. اگه سرور خاموش بشه یا کرش کنه، بات از کار می‌افته. نگه‌داشتن همچین سروری معمولاً هزینه داره و نیاز به مدیریت (آپدیت، ری‌استارت، مانیتورینگ) داره.

**Cloudflare Workers (چیزی که این بات روش کار می‌کنه):**
به‌جای یه سرور همیشه‌روشن، کد بات روی هزاران سرور Cloudflare در سراسر دنیا پخش شده. وقتی تلگرام یه پیام جدید داره، مستقیم یه درخواست HTTP (webhook) به آدرس بات می‌فرسته. Cloudflare همون لحظه، در کمتر از چند میلی‌ثانیه، کد رو روی نزدیک‌ترین سرور به فرستنده اجرا می‌کنه، جواب رو تولید می‌کنه، و دوباره خاموش می‌شه.

یعنی:
- **هیچ سروری نداری که خاموش بشه** — چون از اول سروری وجود نداره که بخوای روشن نگه‌داری
- **همیشه در دسترسه** — چون Cloudflare خودش زیرساخت رو مدیریت می‌کنه، نه تو
- **رایگانه** (تا سقف ۱۰۰,۰۰۰ درخواست در روز، که برای یه بات گروهی خیلی بیشتر از نیازه)
- **نیازی به کامپیوتر روشن یا لپ‌تاپ تو نداره** — بعد از دیپلوی، حتی اگه سیستم خودت رو خاموش کنی، بات کار می‌کنه

تنها نکته: چون Workers خودش «حافظه» نداره (هر اجرا از صفر شروع می‌شه)، اطلاعات (اعضا، بدهی‌ها، تاریخچه) باید یه جای دیگه ذخیره بشه. برای این کار از **Cloudflare KV** استفاده شده — یه پایگاه‌داده‌ی سبک key-value که هم رایگانه و هم همیشه در دسترسه، دقیقاً مثل خود Worker.

خلاصه: بات تو الان مثل یه سرویس ابری واقعی کار می‌کنه، بدون اینکه لازم باشه پول سرور بدی یا نگران خاموش‌شدنش باشی.

## دستورات بات

| دستور | کاربرد |
|---|---|
| `/add <اسم مستعار>` | عضویت در سیستم، یا تغییر اسم مستعار |
| `/members` | نمایش لیست اعضای ثبت‌شده |
| `/expense` | شروع ثبت یک هزینه‌ی جدید (با دکمه‌های تعاملی) |
| `/balance` | نمایش وضعیت بدهی/طلب هرکس |
| `/settle <نام گیرنده> <مبلغ>` | ثبت واریز پول از خودت به یه نفر دیگه |
| `/history` | نمایش ۱۵ تراکنش اخیر |
| `/cancel` | لغو فرآیند ثبت هزینه‌ی نیمه‌کاره |
| `/help` | نمایش راهنما |
| `/start` | پیام خوش‌آمدگویی |

### ثبت هزینه (`/expense`)

بعد از زدن `/expense`، دو دکمه میاد:

**۱. تقسیم مساوی بین همه‌ی اعضا**
یه پیام دوخطی بفرست:
```
90000
خرید نون
```
(خط اول مبلغ، خط دوم توضیح)

**۲. تقسیم غیرمساوی (سهم دلخواه)**
هر خط یه اسم و مبلغ، خط آخر توضیح:
```
علی 20000
رضا 15000
مریم 25000
پیتزا
```

### تسویه‌حساب (`/settle`)

وقتی می‌خوای برای یه نفر پول واریز کنی:
```
/settle علی 200000
```
این یعنی: خودت داری ۲۰۰,۰۰۰ تومان برای علی واریز می‌کنی. بدهی خودت کم می‌شه (یا طلبت زیاد می‌شه) و بدهی علی زیاد می‌شه.

## منطق حساب‌وکتاب

هر عدد توی سیستم یه **بدهی خالص (net balance)** هست:
- 🟢 عدد مثبت = طلبکاره (بقیه بهش بدهکارن)
- 🔴 عدد منفی = بدهکاره (به بقیه بدهکاره)
- ⚪ صفر = تسویه

**قانون کلی:** وقتی هزینه‌ای ثبت می‌شه، کل مبلغ به‌عنوان طلب به واردکننده اضافه می‌شه، و هرکس (از جمله خودِ واردکننده اگه جزو سهم‌ها باشه) به‌اندازه‌ی سهمش بدهکار می‌شه.

**مثال:** ۴ نفر (شخص۱ تا ۴)، شخص۱ مبلغ ۱۶۰,۰۰۰ تومان رو با تقسیم مساوی بین همه ثبت می‌کنه:
- سهم هرنفر: ۴۰,۰۰۰ تومان
- شخص۱ (پرداخت‌کننده): طلبکار ۱۲۰,۰۰۰ تومان (چون ۱۶۰,۰۰۰ داده ولی خودش هم ۴۰,۰۰۰ سهم داشته)
- شخص۲، ۳، ۴: هرکدوم بدهکار ۴۰,۰۰۰ تومان

## ساختار داده‌ها

همه‌چیز در Cloudflare KV، جدا برای هر گروه (بر اساس `chatId`):

```
members:<chatId>   -> [{ userId, username, nickname }, ...]
balances:<chatId>  -> { [userId]: netBalance }
history:<chatId>   -> [{ type: 'expense'|'settlement'|'restart', ... , ts }]
pending:<chatId>:<userId> -> { type: 'all'|'custom' }   (موقت، برای فرآیند ثبت هزینه)
```

## راه‌اندازی از صفر

### پیش‌نیازها
- [Node.js](https://nodejs.org) نصب باشه
- یه حساب [Cloudflare](https://dash.cloudflare.com/sign-up) (رایگان)
- یه بات تلگرام ساخته‌شده با [@BotFather](https://t.me/BotFather) (توکن لازم داری)

### مراحل

```bash
# ۱. نصب ابزار دیپلوی
npm install -g wrangler

# ۲. لاگین به Cloudflare
wrangler login

# ۳. ساخت پایگاه‌داده‌ی KV
wrangler kv namespace create ROOM_DB
```

خروجی مرحله‌ی ۳ یه `id` بهت می‌ده. اون رو توی `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` کن.

```bash
# ۴. ثبت توکن بات (امن، رمزنگاری‌شده)
wrangler secret put BOT_TOKEN

# ۵. دیپلوی
wrangler deploy
```

بعد از دیپلوی، یه آدرس شبیه این می‌گیری:
```
https://room-bot.YOUR-SUBDOMAIN.workers.dev
```

### وصل کردن به تلگرام

توی مرورگر این آدرس رو با توکن و آدرس خودت باز کن:
```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://room-bot.YOUR-SUBDOMAIN.workers.dev
```
اگه `{"ok":true}` گرفتی، بات آماده‌ست.

## به‌روزرسانی کد

هر وقت کد جدیدی گرفتی:

1. فایل `src/index.js` رو با نسخه‌ی جدید جایگزین کن (فایل `wrangler.toml` رو دست نزن، چون `id` واقعی KV توشه)
2. توی پوشه‌ی پروژه بزن:
   ```bash
   wrangler deploy
   ```
3. همین کافیه — آدرس و توکن ثابت می‌مونن، فقط کد آپدیت می‌شه.

## دستور مخفی

یه دستور `/restart` هم وجود داره که همه‌ی بدهی‌ها و طلب‌های اتاق رو صفر می‌کنه (مثلاً برای شروع دوباره‌ی حساب‌وکتاب). عمداً توی `/help` نمایش داده نمی‌شه چون خطرناکه و نباید تصادفی زده بشه.
